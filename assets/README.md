# Assets

This directory contains Zorya-owned product assets such as icons, branding, UI resources, and packaging artwork.

Rules:

- keep source artwork when practical;
- do not add third-party assets without a compatible license and provenance;
- do not store credentials, signing material, user data, crash dumps, or generated release packages here;
- generated platform variants should be reproducible from their source asset when tooling exists;
- visual assets controlled by Web content belong to Rarog/Web resources, not to Zorya product assets.
