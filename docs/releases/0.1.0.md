# Zorya 0.1.0 Technical Preview

Zorya 0.1.0 is the first public runnable Windows Technical Preview.

This release demonstrates the verified Zorya native-shell and Rarog presentation vertical. It is intentionally incomplete and must not be treated as a general-purpose or production-ready browser.

## Included

- a real native Windows application window;
- Zorya-owned browser state for windows, tabs, navigation intent, history and privileged address-bar state;
- stable tab and navigation identities with stale-completion rejection;
- deterministic local `about:blank` startup content;
- Rarog Web Engine integration pinned to commit `b330f94fd43b6b809ec0d784f6d0d7f2cce44989`;
- off-UI Rarog rendering;
- DX12 presentation through Rarog's public Windows/compositor boundary;
- bounded surface recovery for Rarog-reported surface acquisition failure;
- cooperative render-worker cancellation;
- release-mode and packaged-binary native smoke verification;
- build provenance and a Windows-target-specific third-party license bundle.

## Important limitations

This Technical Preview does not yet provide:

- general HTTP(S) browsing;
- typing, clicking, scrolling or IME input inside Web content;
- complete browser chrome;
- native presentation of multiple Web tabs;
- page-title observation;
- browser profile persistence, history/bookmark storage or downloads;
- full GPU device-loss recovery;
- an installer or automatic updater;
- code signing;
- production security hardening or broad Web compatibility.

The executable is unsigned. Windows SmartScreen or endpoint protection may warn when it is launched.

## Platform

- Windows 10/11
- x86-64
- portable ZIP
- no installation required

## Package verification

The release includes:

- `zorya-0.1.0-windows-x86_64.zip`;
- `zorya-0.1.0-windows-x86_64.zip.sha256`.

The ZIP contains `BUILD-INFO.txt` with the exact Zorya source/build commit, resolved Rarog commit, build target and Rust/Cargo versions. The package also contains Zorya's license and the third-party license index used by the release gate.

## Feedback

Please use the repository issue tracker for reproducible startup, crash and rendering problems. Do not include credentials, private browsing data or other secrets.

Potential security vulnerabilities should be reported through the private process described in `SECURITY.md`, not as public issues.
