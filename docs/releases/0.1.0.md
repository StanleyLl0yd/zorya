# Zorya 0.1.0 Technical Preview

This is the first runnable Windows Technical Preview of Zorya.

## What is included

- a real native Windows application window;
- the Zorya browser-product state model for windows, tabs, navigation, history and privileged address-bar state;
- Rarog Web Engine integration through the exact pinned revision `b330f94fd43b6b809ec0d784f6d0d7f2cce44989`;
- off-UI Rarog rendering;
- DX12 surface presentation through Rarog's public Windows/compositor boundary;
- a deterministic local `about:blank` start document;
- cooperative render-worker cancellation and stale-completion rejection;
- release-mode native smoke coverage before publication.

## Important limitations

This build is a Technical Preview, not a general-purpose browser.

It does **not** yet provide:

- general HTTP(S) page loading;
- typing, clicking or scrolling inside Web content;
- document-title observation from Rarog;
- native presentation of multiple Web tabs;
- an installer, automatic updater or code signing;
- production security hardening or broad Web compatibility.

The executable is unsigned. Windows SmartScreen or other endpoint protection may therefore warn before launch.

## Platform

- Windows 10/11
- x86-64
- portable ZIP; no installation is required

## Verification

The release workflow must build the release profile from the exact release commit, run `zorya.exe --version`, run the full native-window/Rarog/DX12 smoke path, package the result, and publish a SHA-256 checksum.

The checksum file shipped beside the ZIP can be used to verify the downloaded archive.

## Feedback

Please report reproducible crashes, startup failures and rendering problems through the repository issue tracker. Do not include private browsing data, credentials or other secrets in reports.

For a potential security vulnerability, follow `SECURITY.md` instead of opening a public issue.
